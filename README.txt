# Wedding Invitation Website — Sample

This is a responsive sample wedding invitation website.

## Files

- `index.html` — main page
- `style.css` — design and responsive layout
- `script.js` — music play/pause
- `music/wedding-sample.wav` — original simple instrumental sample
- `images/` — folder reserved for your own photos

## Important: replace the sample information

Open `index.html` and replace:

- Saeid & Niloofar
- 12 September 2026
- Schloss Lichtenwalde
- 09577 Niederwiesa
- `your-email@example.com`

You can also replace the sample Unsplash photo URLs with your own files, for example:

`images/couple.jpg`

and then use:

`<img src="images/couple.jpg" ...>`

## How to test it

The easiest method:

1. Double-click `index.html`.
2. It should open in your browser.
3. Test the music, map, navigation and RSVP buttons.

For best results, use a local web server or upload it to a hosting service.

## How to send it to guests

You normally do NOT send the HTML files through WhatsApp.

Instead:

1. Upload the complete folder to a web host.
2. The host gives you a public URL, for example:
   `https://your-wedding-site.example`
3. Send that URL to your guests through WhatsApp, Telegram or email.

### Free/easy hosting options

- Netlify — drag the website folder onto its upload area.
- GitHub Pages — good if you already use GitHub.
- Vercel — good for more advanced projects.

The included WAV is an original simple sample made for this demo. For your real invitation, replace it with music you are allowed to use. Browsers generally require the guest to tap the music button before audio can start.
